Trains Across City, Countryside and Midnight Views

Computer Graphics, course project

An interactive computer graphics application in which a single train connects three distinct scenes. The user moves between scenes from the keyboard and controls the conditions within each one, so that the train is presented at a city crossing, in a village with changing weather, and from a passenger's viewpoint by day and by night.

Scene 1: city crossroad

A road crossing at which the train and road vehicles move in alternation. The user determines which side has right of way, and each has its own sound effects.

Scene 2: village with dynamic weather

A countryside view that can be switched between sunny and rainy weather.

Scene 3: passenger interior

An interior view of the train that can be switched between day and night lighting.

Memory Museum Card Game

Programming in Python, group project (4 members)

A memory-matching card game developed with Python and Pygame. Each level is based on a famous painting divided into eight pieces. The player flips cards to find matching pairs, and each match restores one piece of the painting. Completing all eight matches reveals the full artwork, unlocks the next level and, if the previous best is surpassed, records a new best result.

Features

  • Five levels, each based on a different painting.
  • Classic flip-two-cards gameplay with shuffling, matching, scoring and win detection.
  • Level unlocking: completing one level opens the next.
  • Best score tracking per level (fewest attempts and fastest time), with "New Record" detection.
  • A statistics screen summarising total, average and best time and attempts across completed levels, calculated with NumPy.
  • Progress saved to a JSON file between sessions, with recovery if the file is missing or corrupted.
  • A "How To Play" screen and a mouse-driven menu interface.

Structure

The code is organised into separate classes: Game manages the screens, input and game loop; Card represents a single flippable, matchable card; and Painting holds level data and image handling. This separation allowed the work to be divided clearly among the four team members.

Smart Queue Management System

Advanced Programming in Web Technologies, course project

A web-based system designed to streamline customer queues. Customers obtain a virtual ticket in place of standing in a physical line and can follow the progress of the queue, which reduces waiting time.

Key functions

  • Virtual ticketing: customers join the queue digitally.
  • Real-time tracking: queue status is visible and updated as it changes.
  • Reduced wait times: a more orderly and efficient flow for customers awaiting service.

The project reflects my interest in user-focused digital products, where a clear and predictable experience for people waiting for service is as important as the underlying system.
